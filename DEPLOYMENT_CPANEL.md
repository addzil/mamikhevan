# Deployment cPanel

Repositori Git dapat berada di lokasi mana pun yang dikonfigurasi pada Git Version Control cPanel. Aplikasi Laravel berada di `/home/mamikhev/public_html/mamikhevan`, sedangkan document root domain utama adalah `/home/mamikhev/public_html`. `.cpanel.yml` memakai direktori checkout Git saat deployment, membangun aset, menjalankan migrasi, lalu menyalin front controller dan `.htaccess` domain utama dari `cpanel-main-domain/`. `.htaccess` aplikasi berada di akar repositori.

## Persiapan server

1. Pilih PHP 8.4.1 atau lebih baru untuk situs dan PHP CLI di akun cPanel. Composer serta Node.js/npm tidak diperlukan di server untuk alur ini.
2. Arsip `cpanel-runtime-no-terminal.zip` sudah masuk repositori Git dan ikut diambil saat **Update from Remote**. Skrip deploy mengekstraknya ke `/home/mamikhev` jika `unzip` tersedia. Jika log menyatakan `unzip` tidak tersedia, buka arsip tersebut di direktori repo melalui File Manager, pilih **Extract**, dan isi tujuan `/home/mamikhev`, lalu jalankan deploy ulang. Arsip berisi `public_html/mamikhevan/vendor/`, `public_html/mamikhevan/public/build/`, `public_html/index.php`, dan `public_html/.htaccess`. Jangan unggah `node_modules`.
3. Siapkan `.env` produksi di `/home/mamikhev/public_html/mamikhevan/.env`. Isi `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://domain-anda` tanpa `/mamikhevan`, dan `APP_KEY`. Konfigurasi MySQL harus memuat `DB_CONNECTION=mysql`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, dan `DB_PASSWORD`. Jangan masukkan kredensial ini ke Git.
4. Bila `APP_KEY` server masih kosong, buat kunci di komputer lokal dengan `php artisan key:generate --show`, lalu salin hasilnya ke `.env` server. Jangan mengganti kunci yang sudah digunakan di produksi.
5. Bila `mamikhevan/public/storage` adalah folder biasa, pindahkan isinya ke `mamikhevan/storage/app/public` sebelum deployment. Skrip tidak menghapus folder tersebut.
6. Pastikan domain dalam `APP_URL` memiliki record A ke **Shared IP Address** atau **Dedicated IP Address** akun cPanel. Record DNS harus dibuat pada pengelola nameserver aktif. Setelah DNS mengarah ke server, aktifkan sertifikat SSL untuk domain tersebut.

Untuk pemasangan manual `index.php` dan `.htaccess`, ikuti [petunjuk penyalinan](cpanel-main-domain/README.md). Jalankan **Update from Remote**, lalu **Deploy HEAD Commit** melalui Git Version Control cPanel. Skrip mengekstrak runtime, memeriksa `vendor/autoload.php` dan `public/build/manifest.json`, lalu menjalankan penemuan paket, migrasi, cache, dan symlink penyimpanan. Deployment mempertahankan `.env` dan isi `storage/`. Setelah selesai, periksa domain utama dan log Laravel di `mamikhevan/storage/logs/` jika ada masalah. Bangun ulang dan commit arsip runtime setiap kali dependensi atau aset frontend berubah.

Jika tombol **Deploy HEAD Commit** nonaktif, periksa direktori repo yang ditampilkan di Git Version Control cPanel dengan `git status --short`, `git branch --show-current`, dan `git ls-files .cpanel.yml`. cPanel memerlukan working tree bersih, branch, dan `.cpanel.yml` yang sudah masuk commit. Jika repo Git berada langsung di `public_html/mamikhevan` dan `.htaccess` aplikasi sudah disalin manual sebelum file ini masuk Git, pindahkan atau cadangkan file tersebut di luar direktori repo sebelum **Update from Remote** agar Git dapat mengambil versi yang dilacak. Periksa file lain yang dibuat manual satu per satu; jangan menghapusnya secara massal.
